## 🏢 About The Project

This is the lightweight, static Landing Page version of the AETHER Architecture platform. It has been stripped of all Firebase backend connections and internal management portals, resulting in a lightning-fast, zero-maintenance digital brochure.

It is designed for architectural practices that want a high-end web presence but do not require complex lead tracking or real-time Content Management Systems.

### ✨ Key Features
- **Brutalist/Minimalist Aesthetics**: Pure black & white high-contrast design (Day/Night Mode) that highlights architectural imagery.
- **Lightning Fast Performance**: Zero database queries. All portfolio and journal data are statically rendered for immediate load times.
- **Inquiry Mockup**: A slide-over contact modal designed for spatial consultations, ready to be hooked up to static email forwarders (e.g., Formspree).
- **Free Hosting**: Since it's a 100% static React App, it can be hosted for free indefinitely on Vercel, Netlify, or GitHub Pages.

## 🚀 Tech Stack
- **Frontend**: React 19, Vite, TypeScript
- **Styling**: Tailwind CSS v4, Framer Motion, Lucide React Icons

## 🛠️ How to Run Locally

1. Clone this repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Access the web app at `http://localhost:3000`.
